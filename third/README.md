# 外部引用

本目录只记录**借鉴过的公开资料与出处**，不收录第三方代码。

原因：诺瓦/卡莱特的私有协议均为现场抓包逆向，参考项目大多带有各自的许可证，部分还捆绑专有运行库（如 NDI SDK 的 `Processing.NDI.Lib.x64.dll`）。直接复制进来既可能有许可证冲突，也会让仓库体积和构建复杂度失控。

## 参考项目

| 项目 | 用途 | 与本项目的关系 |
|---|---|---|
| [olebeck/olebecknovaled](https://github.com/olebeck/olebecknovaled) | 早期的诺瓦接收卡 pcap 直发实现（Go） | 协议理解的起点；内核态发送方案与本项目无关。它的 README 同样指出：接收卡不初始化时，每次重启都得跑一遍 NovaLCT |
| [FPP ColorLight 5a-75](https://github.com/FalconChristmas/fpp) 的 `ColorLight-5a-75.cpp` | 卡莱特接收卡发现包与协议字段 | `colorlight_probe.py` 的 0x07 发现包格式参考 |
| hkubota 的卡莱特逆向笔记 | 卡莱特行包/同步包结构 | 与现场抓包结果互相印证 |

## 厂商资料

| 资料 | 说明 |
|---|---|
| NovaLCT | 诺瓦接收卡配置工具。**断电后必须用它（或 V960）初始化一次**，接收卡才会接受第三方帧流 |
| LEDSetting（卡莱特） | 卡莱特接收卡箱体映射配置。不要发送 `0x02` 布局配置包，否则会覆盖这里配好的映射 |

> 两个厂商的 SDK 均未使用。所有帧格式结论来自本项目自己的抓包与实屏验证，见 `doc/` 下的协议分析文档。
